TASK 1 – STUDENT GRADE TRACKER USING JAVA
1. Introduction

The Student Grade Tracker is a Java-based application developed as part of my CodeAlpha Java Programming Internship.

The main purpose of this project is to manage student academic records and calculate their grades based on the marks obtained in different subjects.

This application helps users enter student marks, calculate total marks, find average marks, calculate percentages, and determine the corresponding grades.

The project demonstrates the practical implementation of Java programming concepts and helps in understanding how student performance can be managed efficiently.

2. Project Objective

The main objective of this project is to develop a simple and user-friendly Student Grade Tracker using Java.

The objectives include:

To enter student names and subject marks.
To calculate total marks.
To calculate average marks.
To calculate percentage.
To assign grades based on performance.
To display student academic details.
To improve programming and logical thinking skills.
3. Project Description

The Student Grade Tracker is a simple application developed using Java programming language.

The application allows users to enter student details and marks obtained in different subjects.

Based on the entered marks, the program calculates the total marks, average marks, and percentage. It then determines the student's grade according to predefined grading criteria.

The application displays the final academic performance of the student in an organized format.

4. Features of the Project
1. Student Information

Allows users to enter student details such as name and other required information.

2. Marks Entry

Allows users to enter marks obtained in different subjects.

3. Total Marks Calculation

Calculates the sum of marks obtained in all subjects.

4. Average Calculation

Calculates the average marks of the student.

5. Percentage Calculation

Displays the student's overall percentage.

6. Grade Calculation

Assigns grades based on the student's marks and predefined grading rules.

7. Result Display

Displays the student's total marks, average, percentage, and final grade.

8. User-Friendly Interface

Provides a simple interface to enter and view student academic information.
